# 💰 Sistema de Planejamento Financeiro Inteligente

Este é um Web App interativo desenvolvido em Python para ajudar no controle de gastos e quitação de dívidas, utilizando a metodologia **50-30-20**.

## 🚀 Funcionalidades
- **Entrada Dinâmica:** Insira sua renda, gastos essenciais e dívidas.
- **Análise em Tempo Real:** O sistema calcula automaticamente o saldo restante.
- **Gráficos Comparativos:** Visualize como seus gastos estão em relação ao modelo ideal de saúde financeira.
- **Alertas de Risco:** Avisos visuais quando o orçamento está negativo ou fora dos limites de segurança.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Interface Web:** Streamlit
- **Processamento de Dados:** Pandas

## 💻 Como Rodar o Projeto
1. Clone este repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o app: `streamlit run app.py`
